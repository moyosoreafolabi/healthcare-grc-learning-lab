# Healthcare GRC Learning Lab

> A 24-week applied cybersecurity governance, risk and compliance portfolio built around a fictional telehealth organisation.

## Project Overview

This repository documents my structured transition into healthcare cybersecurity GRC. It converts weekly learning into practical deliverables covering organisational context, asset management, risk assessment, security controls, policy development, third-party risk, healthcare compliance and executive reporting.

The case study is based on **Meridian Virtual Health**, a fictional telehealth organisation created solely for educational and portfolio purposes.

## Learning Objectives

By the end of the programme, this repository will demonstrate the ability to:

- Understand an organisation before assessing its security risks
- Identify information assets, threats, vulnerabilities and controls
- Build and maintain a cybersecurity risk register
- Apply the NIST Cybersecurity Framework 2.0
- Map risks to security controls and evidence
- Write security policies and operational procedures
- Conduct basic control assessments
- Evaluate third-party security risk
- Interpret healthcare security requirements
- Communicate cyber risk to management

## Frameworks and Guidance

The portfolio will draw from:

- NIST Cybersecurity Framework 2.0
- NIST Risk Management Framework
- Selected NIST SP 800-53 controls
- CIS Controls
- ISO/IEC 27001 concepts
- HIPAA Security Rule guidance
- Healthcare security risk-assessment practices

## Fictional Organisation

**Meridian Virtual Health** is a fictional telehealth provider offering remote consultations, appointment scheduling, electronic clinical documentation, prescription coordination, patient follow-up and billing support.

All names, records, systems, risks and evidence in this repository are synthetic.

## Portfolio Principles

3. Document the reasoning.

5. Review the work before merging it.
6. Record lessons learned.

# GRC Project Scope

## Project Purpose

To create an applied cybersecurity GRC assessment for Meridian Virtual Health, a fictional telehealth organisation.

## In Scope

### People
- Employees
- Clinicians
- Medical virtual assistants
- Contractors
- Managed IT personnel

### Processes
- Patient registration
- Appointment scheduling
- Telehealth consultations
- Clinical documentation
- Prescription coordination
- Patient follow-up
- Billing
- Workforce onboarding and termination
- Vendor management
- Incident reporting

### Technology
- EHR
- Telehealth platform
- Productivity suite
- Appointment scheduler
- Billing system
- Employee endpoints
- Cloud storage
- Email and messaging
- Remote-access services

### Information
- Patient identity data
- Clinical information
- Appointment data
- Billing information
- Employee information
- Credentials
- Vendor and contract records
- Security logs and incident records

## Out of Scope

- Medical-device security
- Physical hospital environments
- Pharmaceutical manufacturing
- Real patient records
- Real employer systems
- Formal legal opinions
- Certification audits

## Success Criteria

- Clear organisational context
- Asset and data inventory
- Documented risk methodology
- Prioritised risk register
- Framework and control mappings
- Policies and procedures
- Control-test examples
- Vendor-risk documentation
- Healthcare security analysis
- Executive report and remediation plan
